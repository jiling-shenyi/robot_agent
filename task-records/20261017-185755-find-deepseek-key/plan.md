## 已知事实与假设

- 项目存在 `src/embodied_agent/models/deepseek.py` 和 `.env.example`。
- 初始 Git 工作区无未提交修改，远端为 `origin`。

1. 检查 DeepSeek 客户端、配置引用及本地环境配置，确认实际读取方式。
2. 查找对应密钥值；必要时只读检查相关环境变量或项目 Git 历史，并区分占位值与真实配置。
3. 创建执行分析，记录来源和完成证据；文档不保存完整密钥。
4. 仅提交本次任务记录并推送，向用户报告密钥值、来源与文档路径。

## 预期产物与完成判据

- 配置文件可能被 Git 忽略：搜索本地隐藏和忽略文件，并排除依赖目录与 Git 内部数据。

- 若推送受网络或权限限制：按工具要求处理，并准确记录结果。
