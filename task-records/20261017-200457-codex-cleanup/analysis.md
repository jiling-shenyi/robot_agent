## 完成判据与证据

1. 语法与兼容性：PowerShell 解析器检查通过；隔离验证在 Windows PowerShell `5.1.26100.9711` 下通过。主脚本文件包含 UTF-8 BOM（`EF BB BF`），启动器使用 ASCII 与 CRLF。
2. 删除范围：隔离环境内真实删除五个模拟目标；相邻的其他 OpenAI 应用、其他程序包、项目文件全部保留。测试用户目录包含空格及方括号，以验证字面路径处理。
3. 重复执行与交互：重复清理返回目标不存在；预览及取消均保留所有模拟文件。
4. 路径保护：父目录、越界路径、未知目标、磁盘根目录和驱动器相对路径全部被拒绝。目标本身、目标内部和祖先路径中的目录联接均被拒绝；联接所指向的外部哨兵文件保留。
5. 前置保护：模拟应用仍安装、程序包查询失败、相关进程运行时均阻止清理；模拟已卸载且无进程时通过检查。
6. 桌面验证：从桌面 CMD 启动器以 `-PreviewOnly` 执行，退出码为 `0`，正确列出之前确认的五个真实目录；窗口输出明确为没有删除任何文件。
7. 真实删除未验证：用户尚未卸载应用，本任务不执行真实数据清理。文件锁或权限问题以运行时逐项结果为准，不保证所有目标在任意权限下均能删除。
